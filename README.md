# 第十三声钟响之前 thirteenth-bell-game

**一座孤岛古堡，一份真假混杂的住客守则，三名各有所求的同行者。**

你收到一份来历不明的邀请，乘渡船来到圣弥迦勒堡。管家已经为你安排好房间，登记桌上的名册却似乎早已知道你的名字。

在第十三声钟响之前，阅读规则、调查现场、核验同伴，找到离开的方法。每一次选择，都可能改变今晚的结局。

## 游戏特点

- **三个玩家身份**：调查记者、心理医生、遗产继承人。可自行选择，也可随机分配。
- **场景点击探索**：点击画面中的物件和人物，查看文字信息，再确认自己的行动。
- **真假规则与现场证据**：七条住客守则逐渐被验证或证伪，线索可随时在手记中回顾。
- **三次主动调查**：不同地点和同行互动提供不同收益，需要决定如何分配机会。
- **角色关系与命运**：同行者会回应你的选择；已经发生的失去不会被剧情自动抹去。
- **分支与多结局**：42 个剧情节点、五种结局，三个身份均可在首次游玩中找到无牺牲的出口。
- **本地自动存档**：保存当前剧情和阅读位置，支持章节回退与重新开始。
- **氛围声音**：不同场景配有环境音乐与点击、钟摆等音效；NPC 无配音，静音也能获得全部判断线索。

游戏以阅读、观察和选择为核心，没有实时战斗或现实倒计时。单局设计目标为 20–35 分钟，实际时长取决于阅读与探索习惯。

## 如何游玩

1. 点击“乘渡船登岛”，在剧情中选择身份或随机身份。
2. 阅读当前对话，通过“继续阅读”查看下一张文字卡片。
3. 点击场景标记查看物件、人物或行动。**查看标记不会直接提交选择**，确认正文中的选项后才会行动。
4. 随时打开“规则”“证据”“地图”或“伙伴”，核对已经获得的信息。这些操作不消耗调查次数。
5. 遇到不可逆选择时，先阅读确认提示；可以返回，也可以按 `Esc` 取消。
6. 在结局页面查看本局记录，选择回退到检查点或重新登岛，体验其他路线。

点击场景空白处可以收起对话，再点击标记或“打开当前对话”即可继续。设置中可调整字号、日夜主题、整段阅读、声音和音量。

## 存档与声音

**存档保存在当前浏览器中。** 在同一网址、同一浏览器重新打开游戏，可继续已保存的进度。换设备、换浏览器或清除网站数据后，存档不会自动同步；隐私模式或浏览器存储限制也可能影响保存。

声音通常需要首次点击后才能启动。没有声音时，可在“设置”中检查声音开关和音量。声音只用于营造氛围，不是解谜的必要条件。

## 项目结构

当前 GitHub Pages 网页上传版以仓库根目录的 `index.html` 为入口：

```text
index.html
favicon.svg
assets/
├── app.js          # 场景、对话、面板及用户交互
├── data.js         # 剧情节点、角色、地图、规则与证据
├── engine.js       # 条件、效果、分支、结局及检查点回退
├── state.js        # 游戏状态与存档结构校验
├── storage.js      # 本地存档、设置与结局记录
├── images.js       # 图片选择、加载、兼容回退及重试
├── sound.js        # 环境音乐与音效
├── style.css       # 页面样式与响应式布局
├── backgrounds/    # 场景原图
├── characters/     # 人物原图
└── thumbnails/     # 地图缩略图
```

完整开发包另包含 `public/`、`tests/`、`scripts/` 和 GitHub Actions 工作流；其中 `public/` 对应上面的网页运行文件。

## 本地预览

如果使用当前仓库的网页上传版，并已安装 Python，在仓库根目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)。

如果使用包含 `package.json` 的完整开发包，安装 Node.js 20 或更新版本，在项目目录运行：

```sh
npm test
npm run dev
```

打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。基础检查和预览无需安装第三方依赖。本地与线上网址的存档分别保存。

## 部署与更新

当前网页上传版使用 **GitHub Pages → Deploy from a branch → main → / (root)**。修改后将网页文件提交到 `main`，等待 Pages 部署完成即可更新。

完整开发包也提供 GitHub Actions 发布方式：工作流先执行 `npm test`，再发布 `public/`。采用此方式时，应将 Pages 的 Source 改为 **GitHub Actions**。

### 图片加载优化

本地 2.2.0 开发版已加入 WebP、手机场景图、轻量头像、首屏预加载及下一场景预取。手机封面由约 352 KB 减至 59 KB，原 JPEG/PNG 保留为兼容回退。上传图片加速更新包后，仓库中会新增 `assets/optimized/v2/`，这些优化才会在线生效。

线上版本以仓库最近一次成功部署的内容为准。文件体积减少比例不等于实际加载时间减少比例，加载体验也受网络状况影响。
